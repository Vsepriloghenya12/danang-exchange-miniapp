# Cash a Lot: локальный вариант интерфейса

## Направление

Калькулятор — главный элемент экрана. Фирменный кит встречает клиента в шапке
и повторяется в кнопке отправки. Жёлтый цвет обозначает действие и выбор,
а крупные суммы помогают проверить обмен до отправки.

## Основные настройки

- Жёлтый: `#F6C600`, основной акцент.
- Глубокий синий: `#002333`, логотип и текст.
- Фон: `#F4F6F7`; поверхность: `#FFFFFF`.
- Вторичный текст: `#60747D`; разделители: `#DEE5E8`.
- Тёмная тема: фон `#10242D`, поверхности `#19343F`, текст `#EEF5F6`.
- Manrope для интерфейса и сумм, существующий Circular для названия бренда.
- Суммы с табличными цифрами, подписи обычным регистром.

## Компоновка

```text
Кит + Cash a Lot         язык / тема / друзья
Дананг, часы работы            статус / условия
Обмен                 Банкоматы          Отзывы
┌ Вы отдаёте                  минимум ┐
│ 25 000                       RUB ▾ │
├──────────────── ↕ ─────────────────┤
│ Вы получаете                       │
│ 7 500 000                    VND ▾ │
└────────────────────────────────────┘
Курс пары                     время обновления
Оплата                              [Перевод]
Получение            [Наличные][Перевод][ATM]
Комментарий / адрес / реквизиты           скрепка
[ Кит            Отправить заявку          → ]
Согласие и документы
Курсы сегодня                       Все курсы
RUB → VND         USDT → VND         USD → VND
Обмен             Оплаты       История     Ещё
```

Основной сценарий остаётся на первом экране телефона. Подробные курсы —
в отдельном окне, условия и дополнительные разделы доступны по нажатию.
При клавиатуре, предупреждениях, увеличенном шрифте и очень низком экране
прокрутка сохраняется, чтобы элементы не обрезались.

## Проверка концепции перед реализацией

Убираем одинаковые карточки, градиенты и свечение у каждого элемента:
они делали все действия равноценными. Единственный крупный жёлтый элемент —
отправка заявки. Калькулятор объединён в одну поверхность. Курсы показываются
короткой горизонтальной строкой. Информация и бизнес-правила сохраняются.

Анимации отвечают на действие: смена пары, поворот кнопки обмена валют,
открытие подробных курсов. Учитывается настройка уменьшения движения.

После локального просмотра пользователь согласовал применение дизайна
в тестовой ветке `codex/new-features`. Она разворачивается в `cashalot-test`
на Railway. Локальный предпросмотр остаётся доступен для следующих правок.

## Запуск

`npm run design:preview` собирает интерфейс и открывает локальный сервер на
`http://127.0.0.1:5188/design`. На странице можно менять тему, размер телефона
и демонстрационное рабочее время. Приложение использует временное хранилище
и пример курсов. Отправка заявок отключена, бот не запускается.

После правок перезапустите команду и обновите страницу. Сборка нужна, чтобы
предпросмотр точно соответствовал собранным компонентам. Файл
`scripts/design-preview.mts` служит только локальному просмотру и не включается
в команду запуска Railway.
