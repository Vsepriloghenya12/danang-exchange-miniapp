# Твой Вьетнам — Дананг

Автоматическая лента для туристов и жителей Дананга. Национальные новости допускаются только о въезде и правилах, влияющих на поездку в Дананг. Название канала — «Твой Вьетнам».

## Визуал

Сохраняем Manrope для заголовков и Inter для текста. Палитра: морской #002B39, жёлтый #FFCF26, белый #FFFFFF, светлый #F5F7F8, вторичный #647981. Используем существующие переменные темы.

Шапка — «Дананг» с авторской векторной линией моста и моря. Рубрики прокручиваются горизонтально. Первая публикация крупнее, далее компактные заголовки с датой, источником и коротким анонсом. Текст выравнивается влево. Отдельная вкладка «Новости» рядом с «Обмен», «Банкоматы» и «Отзывы»; форма обмена и её высота сохраняются.

Проверка концепции: вместо одинаковых карточек с декоративными фотографиями делаем городской журнал с одним узнаваемым рисунком. Не выдаём иллюстрацию за фотографию места. Не используем чужие фотографии без разрешения.

## Работа

- RSS проверяются каждые 15 минут. Источники выбираются из проверенного списка; произвольные адреса сервер не загружает.
- Для начала — русскоязычные АТОР и ТурДом. VnExpress доступен отдельно с пометкой английского языка; автоматического перевода в первой версии нет.
- В ленту попадают свежие материалы с явным упоминанием Дананга и национальные изменения правил въезда. Отбор по заголовку и анонсу, а не по рекламным блокам полной статьи.
- Короткий анонс и ссылка на оригинал; полные чужие статьи не копируются. При отсутствии подходящих новостей лента не заполняется выдуманными событиями.
- У владельца: источники, пауза, скрытие, собственные публикации, канал, ошибки обновления и отправки.
- Публикация в канал — до 3 новостей в день, с интервалом минимум 2 часа, с 08:00 до 21:00 по Данангу. Старые материалы при подключении канала не рассылаются.
- Повторная отправка после неопределённого результата Telegram автоматически не выполняется: владелец проверяет канал. Канал новостей не использует настройки канала заявок или курсов.
