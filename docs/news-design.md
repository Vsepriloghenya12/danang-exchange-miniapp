# Твой Вьетнам — Дананг

Автоматическая лента для туристов и жителей Дананга. Национальные новости допускаются о въезде и правилах поездки. Канал: https://t.me/tvoi_vietnam_danang.

## Визуал

Manrope для заголовков, Inter для текста. Палитра приложения: морской #002B39, жёлтый #FFCF26, белый #FFFFFF, светлый #F5F7F8, вторичный #647981; существующие переменные светлой и тёмной темы.

Страница без собственных карточек, фонов и рамок. Заголовок «Твой Вьетнам», короткая подпись о Дананге, текстовые рубрики с жёлтым подчёркиванием выбранной. Новости разделены свободным пространством; первая имеет более крупный заголовок. Сохранение и подписка — ненавязчивые текстовые действия. Выравнивание влево, одна читаемая колонка.

Проверка концепции: убрали рисованную кодом заставку и повторяющиеся контейнеры по запросу владельца. На странице нет декоративной фотографии, отвлекающей от новостей. Для аватара Telegram создан отдельный фотореалистичный образ Дананга, не документальный снимок: server/public/brand/news/tvoi-vietnam-avatar.png.

## Источники

- АТОР и ТурДом по RSS каждые 15 минут. VnExpress отдельно, на английском без перевода. Короткий анонс и ссылка на сайт сохраняются.
- Telegram: владелец добавляет бота приложения в выбранный канал и подключает @имя/ID в разделе «Telegram-источники». Используется официальный channel_post; доступ к чужому каналу без добавления бота не обещается.
- Подключать следует тематические каналы о Дананге, с разрешением использовать тексты. Принимаются новые тексты и подписи после подключения. История не импортируется; фото и видео новых сообщений сохраняются вместе с подписью. Защищённые сообщения пропускаются.
- Telegram-источник хранится для владельца; клиентский API и публикации нашего канала не выводят его имя и ссылку. Сайты сохраняют атрибуцию.
- Список каналов-источников пока пуст: владелец ещё не выбрал каналы.
- Повторы по ID и близким заголовкам не добавляются. Канал назначения нельзя подключить как источник, чтобы не создавать цикл.

## Публикация

До трёх материалов в день, интервал минимум два часа, 08:00–21:00 по Данангу. Старые материалы при подключении не рассылаются. Пауза останавливает импорт и отправку. После неоднозначной ошибки Telegram повтор не отправляется автоматически.

## Публичные Telegram-каналы без добавления бота

Владелец → Новости → Telegram-источники → «По ссылке, без бота». Принимаются @имя и ссылки https://t.me/имя (также /s/имя и ссылка на конкретный пост). Закрытые приглашения, группы без открытой веб-ленты и каналы с недоступным предпросмотром не подключаются. Не нужны личный Telegram-аккаунт, номер телефона, API ID или токены сторонних сервисов.

При подключении фиксируется последний номер сообщения. История не импортируется. Раз в 15 минут сервер читает публичную веб-страницу t.me/s/имя, извлекает видимые тексты и подписи новых сообщений; импортируются фото, видео и альбомы, доступные в веб-просмотре Telegram. Источник остаётся в панели владельца, но скрывается в клиентской ленте и исходящих публикациях. Существующий способ через бота сохранён.

До 10 публичных источников; 4 параллельных чтения, до 3 страниц за проверку, таймаут 10 секунд на страницу, не более 2 МБ HTML. Только фиксированный HTTPS-хост t.me, без перехода по перенаправлениям, cookies и выполнения скриптов. При недоступности или слишком большой очереди номер последнего сообщения не меняется, владелец видит ошибку. Повторная проверка не дублирует новости; удаление и повторное подключение во время сбора не принимают результат предыдущего подключения. Собственный канал назначения нельзя использовать как источник.

Веб-предпросмотр Telegram не является гарантированным RSS/API: при изменении его разметки парсер может потребовать обновления. Сбор не обходит закрытие канала или ограничения доступа. Каналы ещё не выбраны владельцем; проверка проведена чтением официального публичного @telegram без добавления его в рабочие источники.

## Фото и видео

Фото, MP4-видео и смешанные альбомы до 10 вложений показываются внутри публикации. Галерея листается по горизонтали; видео запускается пользователем, без автозагрузки. Публикации без подписи также импортируются. Аватары, картинки предпросмотра ссылок и защищённые сообщения не импортируются. Недоступные в веб-просмотре вложения отмечаются у владельца и в ленте.

В наш канал отправляются sendPhoto / sendVideo / sendMediaGroup; длинная подпись сохраняется отдельным сообщением после вложений. Идентификаторы уже отправленных сообщений сохраняются до следующего шага: при частичном сбое автоматического повтора нет. Альбомы через channel_post собираются по media_group_id, сортируются по message_id и допускаются к отправке через минуту после последнего вложения. Уже импортированные публичные посты получают обновлённые вложения при очередном чтении, без повторной рассылки.

Приложение получает только адреса собственного /api/news/media/:id/:index. Сервер проверяет видимость публикации, скрывает токен и file_id, ограничивает загрузку 10 МБ для фото и 50 МБ для MP4, 100 МБ на отправляемый альбом. Через Bot API getFile доступно скачивание до 20 МБ; большие видео можно переслать в канал по file_id, но показ в приложении ограничен API Telegram. Документация: https://core.telegram.org/bots/api#sending-files и https://core.telegram.org/bots/api#getfile.

Публичные медиа скачиваются только с проверенных HTTPS-адресов cdnN.telesco.pe/file/, без перенаправлений. Проверяются MIME и сигнатура файла. Просроченные ссылки обновляются через исходную публичную страницу. Дисковый кэш находится в системной временной папке cashalot-news-media-v1; старые файлы удаляются через 7 дней или при превышении 512 МБ (недавно загруженные файлы сохраняются на час для текущих просмотров). После перезапуска кэш можно восстановить из источника, но это не постоянный архив удалённых Telegram-постов. Одновременно скачиваются два файла, очередь ограничена двадцатью; видео поддерживает Range-запросы для перемотки.

Проверки: разбор одиночных файлов/смешанного альбома/поста без подписи, безопасность URL и размера, обновление истёкшей ссылки, скрытие внутренних данных, сбор альбома из событий не по порядку, частичный сбой отправки без дублей, выдача видео диапазонами и запрет скрытых публикаций. Локальный просмотр: node --import tsx scripts/news-preview.mts --media (изолированные данные, без отправки в канал).
